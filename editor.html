When you choose a local image, video, song, or cursor, the editor embeds that file directly inside index.html as a data URL. That means you do not need an assets folder. Large MP4s or songs can make index.html huge, so shorter/compressed media is better for GitHub Pages. Browsers also require a click before audio with sound can start.
